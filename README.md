# 請求書PDF 一括リネーム

請求書などのPDFを、**取引年月日・取引先・金額**を含むファイル名にまとめて付け直し、ZIPで書き出すツールです。

電子帳簿保存法の「検索機能の確保」に対応するため、受け取ったPDFを1件ずつ手作業でリネームしている方向けに作りました。

👉 **[ツールを開く](https://raku-programmer.github.io/denchoho-rename/)**

---

## ファイルは送信されません

このツールは、選んだPDFを**どこにも送信しません**。読み込みもリネームもZIP化も、すべてお使いのブラウザの中だけで処理されます。サーバーにアップロードする仕組みは存在しません。

### 確かめ方

1. ツールのページで `F12` を押して開発者ツールを開く
2. 「ネットワーク」タブを選ぶ
3. その状態でPDFを読み込み、ZIPを保存する

ファイルの送信は発生しません。ページを開いた直後にZIP生成ライブラリ（JSZip）をCDNから読み込みますが、それ以降は外部との通信はありません。

ソースコードはこのリポジトリの [`index.html`](index.html) がすべてです。1ファイルなので、`fetch` や `XMLHttpRequest` が使われていないことをその場で確認できます。

### 社内で使う場合

`index.html` を保存して社内の共有フォルダに置き、そこから開いても同じように動きます。インターネットに接続していない環境でも使えます（その場合はJSZipをリポジトリに置いて相対パスで読み込んでください）。

## 使い方

1. PDFをまとめてドラッグ＆ドロップする
2. 各行に「取引年月日・取引先・金額」を入力する（「表示」を押すとPDFの中身を確認できます）
3. 「リネームしてZIPで保存」を押す

出力されるファイル名の形式:

```
20260728_株式会社サンプル商事_110000_請求書.pdf
```

「書類の種類」は任意です。空欄にすると `20260728_株式会社サンプル商事_110000.pdf` になります。

### キーボード操作

大量に入力するときは、マウスを使わないほうが速いです。

| キー | 動作 |
|---|---|
| `↑` `↓` | 上下の行へ移動 |
| `←` `→` | 左右の項目へ移動（カーソルが端にあるとき） |
| `Enter` | 下の行へ移動 |
| `Tab` | 次の項目へ移動 |

移動先の入力欄は中身が全選択されるので、そのまま打てば上書きになります。

## 入力チェック

ファイル名として成立しない入力は、エラーを表示して止まります。**使えない文字を勝手に別の文字へ置き換えることはしません。**

取引先名が知らないうちに書き換わると、あとで検索したときに見つからなくなるためです。気づけない不具合になるより、その場で直してもらう設計にしています。

チェックしている内容:

- 取引年月日が8桁であること、かつ実在する日付であること（`20260231` はエラー）
- ファイル名に使えない文字（`\ / : * ? " < > |`）が含まれていないこと
- 制御文字が含まれていないこと
- 末尾がピリオドで終わっていないこと（Windowsが黙って削除するため）

前後の空白は、半角・全角ともに自動で取り除きます。名前の途中の空白はそのまま残します。

同じファイル名が複数できる場合は、ZIP内で上書きされないよう自動で連番が付きます。

---

## できないこと

現時点では、以下は対応していません。

- PDFからの日付・金額の自動読み取り（すべて手入力です）
- スキャンした画像PDFの文字認識（OCR）
- 命名規則のカスタマイズ（区切り文字や項目の順番の変更）
- 台帳CSVの出力

一度に処理する件数が多いとブラウザのメモリを消費します。100件を超える場合は分けて実行してください。

## 注意

**このツールは、検索要件を満たすファイル名を付けるための補助ツールです。電子帳簿保存法への対応が完了することを保証するものではありません。**

- 検索機能の確保は要件の一部です。真実性の確保（事務処理規程の整備、タイムスタンプの付与など）は別途ご確認ください
- ファイル名の付け方そのものは法令で定められているわけではありません。命名の順序や区切り方は、社内ルールや顧問税理士の指示に合わせてください
- 一定の条件下では検索要件への対応が不要となる猶予措置もあります。自社が該当するかは所轄の税務署や税理士にご確認ください

出力されたファイル名の内容が正しいかどうかは、必ずご自身で確認してください。

## 技術メモ

ビルド不要の単一HTMLファイルです。フレームワークは使っていません。

- PDFプレビューは `URL.createObjectURL()` で作ったblob URLを `<iframe>` に渡しているだけです。pdf.js は使っていません
- 外部から読み込むのは [JSZip](https://stuk.github.io/jszip/) のみ。Webフォントも読み込んでいません
- ファイル分割せず1枚にまとめているのは、保存して持ち帰れることと、ソース全体をその場で読めることを優先したためです

作った経緯や実装の詳細は、記事に書いています。
